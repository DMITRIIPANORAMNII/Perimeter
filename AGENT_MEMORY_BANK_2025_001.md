- **Лицензия**: GPLv3

- **Деформируемая местность** в реальном времени
- **Морфинг юнитов** - уникальная система трансформации
- **Энергетическая сеть** и защитные щиты
- **Сюрреалистичные миры** с уникальной атмосферой
- **Терраформинг** - изменение ландшафта

#### **Архитектура проекта**
```
Perimeter/
├── Source/                 # Исходный код (основная часть)
├── cmake/                  # CMake модули
├── docker/                 # Docker конфигурации
```
